# Business Website

Live site: https://wadialababilinfotech.com/

## Tech Stack

- Laravel 12
- PHP 8.2+
- React
- Vite

## Requirements

- PHP ^8.2
- Composer
- Node.js

## Installation

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
```

## Development

```bash
npm run dev
```
